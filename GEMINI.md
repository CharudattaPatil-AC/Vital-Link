# LifeLink Project Guidelines & Automated README Sync

## Workspace Guidelines
- **Always Keep README in Sync:** Whenever code, API routes, database schemas, frontend components, or dependencies are added or modified, update `README.md` to reflect the latest functionality.
- **Dedicated Subagent:** The `readme-updater` subagent is defined and available in this workspace to automatically review and document changes.
- **Documentation Standards:** Ensure all endpoints, roles, and setup commands match the implementation in `backend/` and `frontend/`.
